# Router from prompt vectors vs hand-made cells

125 prompts, 8-fold by family x 10 repeats. Each feature set predicts per-prompt (time, retention, quality_kept) for every arm in-fold; one LP over the held-out fold's predictions picks per-prompt arm distributions (internal floor on a grid). Speed is compared at matched realized quality: the fastest policy (or two-policy mix) whose out-of-fold min(mean ret, mean Q) reaches tau, so a predictor that overpromises gets no credit. 95% CI: family bootstrap.
