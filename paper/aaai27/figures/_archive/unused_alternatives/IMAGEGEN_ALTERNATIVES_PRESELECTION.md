# Figure Alternatives

Each main-paper figure has a deterministic, publication-auditable version and an ImageGen visual alternative. The default manuscript currently points to the deterministic files.

| Figure | Deterministic source | ImageGen alternative | Prompt |
|---|---|---|---|
| TALH overview | `fig_talh_overview_vector.png` | `fig_talh_overview_imagegen.png` | `imagegen_prompt_talh_overview.md` |
| Quality--efficiency | `fig_quality_efficiency_vector.png` | `fig_quality_efficiency_imagegen.png` | `imagegen_prompt_quality_efficiency.md` |
| Component evidence | `fig_component_evidence_vector.png` | `fig_component_evidence_imagegen.png` | `imagegen_prompt_component_evidence.md` |
| Qualitative comparison | `fig_qualitative_deterministic.png` | `fig_qualitative_imagegen.png` | `imagegen_prompt_qualitative.md` |

The ImageGen versions are design candidates. Quantitative plots must be audited and rebuilt from the deterministic plotting scripts before publication. The qualitative ImageGen alternative must not be used as scientific evidence unless all embedded frame pixels are verified unchanged; the deterministic qualitative plate remains the authoritative version.
