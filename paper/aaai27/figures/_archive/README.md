# Archived Figure Assets

Nothing under this directory is a manuscript input.

- `unused_alternatives/` contains rejected visual variants and their prompts. They are retained only for comparison and provenance.
- `selected_source_backups/` contains byte-identical native-render backups of the selected canonical Figs. 3 and 4.

The locked selection and canonical filenames are recorded in `../FIGURE_SELECTION.md`.
