# InTraScale Supplementary Media

All included comparisons are synthetic videos with no author images, voices,
institutional logos, or campus scenes. Each group uses an identical prompt and
seed across methods. Every included video was parsed directly from the MP4
container and verified as 1248x720, 81 frames, 16 fps, and 5.0625 seconds.

The misleading legacy files named `01_Native-HR.mp4` were excluded because
direct inspection showed 640x368 resolution rather than 720p.
